# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?

- Building a UI imperatively requires you to micromanage every program aspect, while building declaratively only requires you to say what outcome you want and and the system figures out how to achieve it.

2. Why must a component name start with a capital letter?

- This is to differentiate custom components you generate from built-in HTML elements.

3. What does a fragment <>...</> do, and why not just use a <div>?

- a fragment groups multiple elements together without adding extra node, while adding an extra <div> inserts a block-level element which can destructure the DOM in HTML.

4. Name one benefit of splitting the UI into small components.

- It will help with the code's reusability that can save development time and ensures consistency across the UI.
